# Safespring Backup security and compliance

These pages describe the security controls and operational practices currently
documented for Safespring Backup:

* [System protection and maintenance](system-protection-maintenance.md) covers
  malware protection, vulnerability management, transport encryption, and TLS
  configuration.
* [Data management](data-management.md) covers retention, deletion,
  decommissioning, backup, and recovery behavior.
* [Network security](network-security.md) covers firewall rules, encrypted
  transport, and network separation.
* [Development and operations management](development-operations-management.md)
  covers environment separation, change management, and handling of customer
  data outside production.

For certifications and standards that apply across services, see [Safespring
security and compliance](../../security-compliance/index.md).

!!! note "Control numbering"
    Numbered headings follow Safespring's shared control taxonomy. A missing
    number means that this site does not publish a Backup-specific statement
    for that control.
